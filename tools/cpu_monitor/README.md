# نمایش دمای CPU و ثبت زمان بوق

ابزاری مستقل برای ویندوز است و به ربات یا تنظیمات آن وابستگی ندارد. پایتون لازم ندارد؛ با Windows PowerShell 5.1 و .NET Framework اجرا می‌شود.

## اجرا

روی **Start.cmd** دوبار کلیک کن و درخواست دسترسی Administrator ویندوز را تأیید کن. این دسترسی برای درایور سنسور CPU لازم است. دفعهٔ اول، نسخهٔ قابل حمل Libre Hardware Monitor 0.9.6 از گیت‌هاب رسمی دریافت و SHA-256 آن بررسی می‌شود. راه‌انداز، درایور **PawnIO** همراه همین نسخهٔ رسمی را در صورت نبودن یا قدیمی بودن نصب می‌کند؛ این درایور روی ویندوز باقی می‌ماند و از Installed apps قابل حذف است. فایل‌های قابل حمل داخل `.runtime` همین پوشه می‌مانند. این ابزار کاری به اجرای خودکار ویندوز، تنظیم فن، BIOS یا تنظیمات امنیتی ندارد.

پنجره، بیشترین دمای لحظه‌ای سنسورهای CPU، دمای هر هستهٔ در دسترس، درصد استفاده و بیشترین دمای ثبت‌شده در این اجرا را نمایش می‌دهد. هر دو ثانیه گزارش ذخیره می‌شود. خود ابزار هیچ بوق یا صدایی ایجاد نمی‌کند.

وقتی بوق شنیدی روی **I heard a beep** کلیک کن؛ کلید **F8** هم وقتی همین پنجره فعال است کار می‌کند. زمان کلیک و زمان آخرین نمونه جدا ثبت می‌شوند تا فاصلهٔ بین شنیدن بوق و نمونه‌برداری مشخص باشد.

دکمهٔ **Save recent system events** حداکثر ۲۰۰ خطا/هشدار System در ۴۸ ساعت گذشته را ذخیره می‌کند. این کار دستی است؛ رویدادهای ذخیره‌شده ممکن است ربطی به بوق نداشته باشند. **Open logs folder** گزارش‌ها را باز می‌کند. با بستن پنجره، نمونه‌برداری متوقف و دسترسی ابزار به سنسورها بسته می‌شود.

## گزارش‌ها و محدودیت‌ها

- `logs/temperatures-*.csv`: زمان با منطقهٔ زمانی، بیشترین دمای CPU، بار CPU و دمای سنسورها.
- `logs/beeps-*.csv`: علامت‌های دستی شنیدن بوق و آخرین نمونهٔ مرتبط.
- `logs/system-events-*.csv`: رویدادهایی که دستی ذخیره کردی.
- دمای ناموجود به صورت خالی / **Temperature unavailable** ثبت می‌شود؛ مقدار تخمینی به جای آن قرار نمی‌گیرد. ACPI Thermal Zone به عنوان دمای CPU استفاده نمی‌شود.
- نارنجی شدن در ۹۰ درجه فقط آستانهٔ مشاهدهٔ قابل تنظیم است؛ حد رسمی ایمنی پردازنده یا اثبات علت بوق نیست.
- بوق نرم‌افزار، کلیدهای دسترس‌پذیری، هشدار شارژ و بوق سخت‌افزار را نمی‌توان فقط با دما از هم تشخیص داد. بوق firmware الزاماً رویداد ویندوز ندارد. این ابزار صدا را ضبط یا منشأ آن را خودکار شناسایی نمی‌کند.
- اگر با دسترسی Administrator هم دما نیامد، ممکن است درایور سنسور مسدود یا سخت‌افزار پشتیبانی‌نشده باشد. تنظیمات امنیتی ویندوز را برای این ابزار غیرفعال نکن.
- اجرای مستقیم `Monitor.ps1` درایور نصب نمی‌کند؛ برای راه‌اندازی اولیه از `Start.cmd` استفاده کن.
- گزارش‌ها و کتابخانهٔ دانلودشده وارد Git نمی‌شوند. گزارش رویداد ممکن است مشخصات محلی سیستم داشته باشد؛ قبل از اشتراک‌گذاری بررسی کن. برای پاک کردن تاریخچه، پس از بستن برنامه پوشهٔ `logs` را پاک کن.

تنظیم فاصلهٔ نمونه‌برداری و آستانه، در Windows PowerShell بازشده با دسترسی Administrator از همین پوشه:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Monitor.ps1 -IntervalSeconds 3 -WarnTemperature 95
```

نمونه‌برداری یک‌باره برای بررسی اتصال سنسور:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Monitor.ps1 -Once
```

بررسی تبدیل داده‌ها بدون دسترسی سخت‌افزار: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Test.ps1`.
